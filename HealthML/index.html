Python ML for Health: from first tests to a PhD-ready toolkit

Nine phases for a second-year computer science student graduating in 2028. Everything is Python and PyTorch. The goal is one open-source evaluation toolkit for clinical AI, built up from small projects, plus the evidence trail a PhD or Global Talent application needs.

Left out on purpose: Java, Kafka, Spark, distributed-systems builds, agent frameworks (LangChain and similar), cloud infrastructure and SaaS-style projects. Add them back only if you pivot toward data engineering or applied LLM product work. Dates are targets, so slide them if a term gets heavy. Global Talent decisions rest on independent recognition, not on finishing a checklist, so treat the evidence file as the real deliverable and check current Home Office and endorsing-body guidance before relying on any plan.
