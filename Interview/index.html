The 10-minute protocol
  1. 0–2 min: restate, ask about edge cases, name the pattern.
  2. 2–4 min: state the approach and complexity aloud.
  3. 4–10 min: code cleanly, dry-run one example.

Targets: Easy ≤ 5 min · Medium ≤ 10 · Hard ≤ 20. No approach after 5 min? Read the hint, then redo cold after 3, 7 and 21 days (the R3/R7/R21 boxes). A problem counts as mastered only when a timed redo lands within target. Codeforces problems are rated by feel (E ≈ 800–1200, M ≈ 1300–1800), so treat their targets as guides.
