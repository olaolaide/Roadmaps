Build the Geometry

Hard-surface

PHASE 03 · BLENDER — SCULPTING & PBR TEXTURING

Give It a Surface

4–5 weeksBlender

Sculpting

  • Dyntopo for freeform organic blocking; Multires for detail passes
  • Retopology: turning a sculpt into an animation-ready mesh

Baking

PHASE 04 · BLENDER — RIGGING

Build the Skeleton

4–5 weeksBlender

Rigging is a discipline of its own at every real studio — a dedicated "rigger" role sits between modeling and animation. Treat it that way here rather than folding it into animation week one.

Skeleton & deformation

  • Armatures, bone hierarchies, bone roll and orientation
  • Weight painting: automatic weights as a start, hand-painting for problem areas
  • Vertex groups and deformation troubleshooting (candy-wrapper joints, volume loss)

Control systems

  • IK vs FK and switching between them mid-chain
  • Rigify: generating a full biped control rig, then customizing it
  • Custom bone shapes, rig layers, and a usable animator-facing UI

Facial & secondary rigs

  • Shape keys (blend shapes) for facial expressions and lip sync
  • Corrective shape keys for joint-bend artifacts
  • Secondary motion: bone-driven cloth/hair jiggle without a full sim
✓ MILESTONE

Rig your hero character with a full Rigify control rig plus a facial shape-key set — deformation-tested through a full range of motion before you animate a single frame.

Course: Rigify official docs + Pierrick Picaut rigging series

PHASE 06 · C++ — STANDALONE TRACK

Learn the Language, Not Just the Blueprint

6–8 weeksC++ (before touching UE's C++ side)

This is deliberately sequenced before Unreal's engine-specific C++ conventions. Learn the language on its own first, the way an engineer would, so you're not debugging syntax and engine architecture at the same time.

Core language

  • Variables, control flow, functions, and compilation basics
  • Classes, inheritance, polymorphism, virtual functions
  • Pointers and references — the concept that trips up most beginners moving from Blueprints

Memory & structure

  • Stack vs heap, manual memory management basics before UE hides it
  • Headers vs source files, include guards, compilation units
  • Standard Template Library: vectors, maps, iterators

Unreal's C++ dialect

  • UCLASS, UPROPERTY, UFUNCTION macros and the reflection system they enable
  • Unreal's smart pointers (UPROPERTY-tracked garbage collection) vs raw std pointers
  • AActor / UActorComponent class hierarchy and the gameplay framework (GameMode, PlayerController, Pawn)
✓ MILESTONE

Write a small non-engine C++ console program first (to prove the fundamentals independent of Unreal), then port the same logic into a UE AActor subclass exposed to Blueprints via UPROPERTY/UFUNCTION.

Course: learncpp.com for language basicsCourse: Unreal's official "C++ Programming" docs + Tom Looman's UE5 C++ guides
PHASE 07 · UNREAL — ENGINE FUNDAMENTALS

Move Into Real Time

5 weeksUnreal Engine 5

Editor & world-building

  • Level editor, actors/components, World Partition for large levels
  • Nanite (virtualized geometry) and Lumen (dynamic GI) — what they replace from baked pipelines

Blueprints, and where C++ takes over

  • Blueprint visual scripting for fast iteration on gameplay logic
  • The real studio pattern: core systems in C++, designer-facing tuning exposed to Blueprint
  • Creating a C++ base class, then extending it in Blueprint (from your Phase 06 work)

Import pipeline

  • FBX/glTF import settings that preserve your Blender materials and scale
  • Collision setup, LODs, and enabling Nanite correctly on static meshes
✓ MILESTONE

Import your Blender environment into a Lumen/Nanite-lit level, and build one interactable object whose logic lives in a C++ class with Blueprint-exposed tuning variables.

Course: Unreal Sensei "Complete Beginner" series
PHASE 08 · UNREAL — CHARACTER & ANIMATION SYSTEMS

Rig It Again, In-Engine

5 weeksUnreal Engine 5

Unreal has its own rigging layer, separate from what you built in Blender — it retargets and re-controls the skeleton for real-time playback and gameplay-driven blending.

Skeletal setup

  • Skeletal Mesh import, physics assets, and skeleton retargeting from your Blender rig
  • IK Rig / IK Retargeter — Unreal's system for reusing animation across different skeletons

Control Rig

  • Unreal's node-based rigging tool — building or importing controls for in-engine posing
  • Driving Control Rig from C++/Blueprint for runtime procedural adjustments

Animation Blueprints & MetaHuman

  • State machines, blend spaces, and layered blending for gameplay-driven motion
  • MetaHuman as a fast path to studio-grade digital humans (optional but high-value)
✓ MILESTONE

Retarget your Blender character animation onto an in-engine skeleton via IK Retargeter, and drive a simple locomotion Animation Blueprint from C++ input.
